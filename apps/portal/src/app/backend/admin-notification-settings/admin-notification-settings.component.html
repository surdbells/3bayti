Customer order updates

Email + push notifications sent to customers about their orders.

Pause per-item order updates to customers paused sending unsaved

When on, customers stop getting an email + push each time a vendor accepts, prepares, ships, delivers or rejects an individual item. This avoids flooding customers on multi-vendor orders, where every store's item updates arrive separately.

Order-level updates and changes made by an admin still notify the customer either way.

You can view this setting but need the settings.edit permission to change it.
