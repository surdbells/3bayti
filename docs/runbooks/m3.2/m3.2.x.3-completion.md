## Executive summary

M3.2.X.3 augments `/v3/categories/:slug` to match the legacy v2 wire
shape exactly, then flips apps/web's `/category/:slug` route to consume
the v3 endpoint. This closes the Day-5 follow-up that left apps/web on
legacy because v3 didn't yet emit the embedded products array + meta
envelope that the category-detail page needs.

Before this phase:
- `apps/web` `/category/:slug` route → legacy `/v2/categories/:slug`
- v3 endpoint returned `{data: {publicShape ∪ children}}` only
- Apps/web's `as unknown as CategoryDetailEnvelope` cast in
  `category-detail.ts` papered over the shape divergence

After this phase:
- v3 endpoint returns `{data: CategoryDetail, meta: {total_products, page_size}}`
- Apps/web feature flag flipped `target='old'` → `'new'`
- Apps/web `/category/:slug` resolves to the new endpoint
- The wire contract is now strictly aligned between backend + apps/web

## Wire contract reference

The endpoint returns the exact shape consumed by apps/web's
`CategoryDetailEnvelope` interface (defined in
`apps/web/src/app/features/categories/category.model.ts`):

```json
{
  "data": {
    "id": 5,
    "slug": "abayas",
    "name": "Abayas",
    "description": "Classic UAE pieces.",
    "display_order": 1,
    "image_url": "https://cdn.example/abayas.jpg",
    "path": "/5",
    "parent_id": null,
    "image": { "url": "https://cdn.example/abayas.jpg" },
    "icon_name": "@tui.sparkles",
    "product_count": 50,
    "children": [],
    "products": [
      {
        "id": 123,
        "slug": "silk-abaya",
        "name": "Silk Abaya",
        "sku": null,
        "price": { "amount": 250.00, "currency": "AED" },
        "sale_price": null,
        "primary_image": { "url": "https://cdn.example/silk.jpg" },
        "category_slug": "abayas",
        "vendor": { "slug": "almas-fashion", "name": "Almas Fashion" },
        "rating": 4.6,
        "review_count": 87,
        "in_stock": true,
        "is_new": false,
        "is_bestseller": false
      }
    ]
  },
  "meta": {
    "total_products": 42,
    "page_size": 20
  }
}
```

Edge cases:
- Empty product set → `data.products: []`, `meta.total_products: 0`, 200 OK (not 404)
- Inactive category → 404
- Unknown slug → 404
- Category with no image → `data.image: null` (not `{url: null}`)
- Category with no icon → `data.icon_name: null`
- Category with mixed active/inactive products → `data.product_count` (raw) ≠ `meta.total_products` (filtered)
