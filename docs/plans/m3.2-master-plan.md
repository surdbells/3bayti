## 1. Milestone boundaries

```
M3.2 — Web greenfield UI + Stream X server leftovers + Stream Z mobile enhancements
   └ apps/web becomes feature-complete (cart/checkout/orders/account/wishlist/etc.)
   └ Stream X items unblock + clean up M3.1.x deferrals
   └ Stream Z items finish mobile post-M3.1.7 enhancements
   └ NEITHER apps/web NOR legacy retirement happen at the END of M3.2
   └ apps/web stays at staging.3bayti.ae throughout (Q-Web-Launch)

M3.3 — Portal migration to v3
   └ Build ~38 net-new admin endpoints
   └ Flip portal feature-by-feature with shadow mode
   └ Portal remains on legacy until each feature flipped
   └ apps/web STILL at staging.3bayti.ae

M3.4 — Cross-surface integration + legacy retirement
   └ RECONCILE-DELETES script + tested against snapshot
   └ EMAIL-CONFLICTS reset campaign (36 users)
   └ 7-day stability windows per surface (mobile / portal / web)
   └ apps/web goes live (Q-Web-Launch trigger)
   └ Legacy MariaDB read-only → archive → decommission
   └ M3 declared closed
```

Total envelope: **~40-50 weeks** of solo work from `dc2a9da` to M3 closure. Calendar-time depends on focus, interruptions, and how aggressively per-phase quality gates surface issues.

## 8. Risks (M3.2-specific)

| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|
| Web greenfield UI takes longer than 6-8 weeks | High | Medium | Phase-by-phase approval gates; descope Tier 2 features to keep schedule |
| Q3 quality infrastructure delays first feature ship | Medium | Low | M3.2.0 is 1 week; if it stretches to 2 weeks, that's still <5% of envelope |
| Noon Apple Pay / Google Pay not available via hosted page | Medium | Low | Defer to M4; not blocking ecommerce-takes-orders bar |
| Faceted search performance on large catalog | Medium | Medium | Postgres GIN indexes + Elasticsearch fallback option if needed |
| Vendor performance metrics computation expensive | Low | Low | Cron-aggregated to materialized view; cached query |
| Push notification permission denials reduce reach | High | Low | Email channel (M3.1.7-H) is primary; push is enhancement |
| Mobile per-order detail page duplicates web detail page work | Low | Low | Share data shape + i18n strings; render differs by platform |
| Stream X items reveal more complexity than estimated | Medium | Medium | Per-sub-phase approval gate catches scope drift before code |
